INICIAR NEXUS - GUIA PASO A PASO PARA WINDOWS

1. QUE DEBE ESTAR INSTALADO

- Node.js 22.12 o superior. npm se instala junto con Node.js.
  Descarga oficial: https://nodejs.org/es/download
  Mantener las opciones predeterminadas del instalador, incluida Add to PATH.
- Visual Studio Code para abrir la carpeta y usar su terminal.
- Un navegador. Para ejecutar las pruebas se necesita Edge o Chrome.
- Conexion a Internet durante la instalacion de dependencias.

No necesitas Python para iniciar el proyecto con React y Node.js.
Despues de instalar Node.js, cierra completamente Visual Studio Code y
PowerShell y vuelve a abrirlos para que reconozcan los comandos.

2. ABRIR LA CARPETA CORRECTA

En Visual Studio Code: File > Open Folder (Archivo > Abrir carpeta).
En la copia local de trabajo, abre:

C:\Users\Vto\Desktop\fronend entrega 2\Proyecto FronEnd\nexus-ep2

Dentro debes ver package.json, pnpm-lock.yaml y la carpeta src.
La carpeta superior Proyecto FronEnd de esa copia NO es la raiz de la
aplicacion React. Debes entrar a nexus-ep2.

Si extraes el ZIP de entrega, abre la carpeta NEXUS_EP2 que contiene
package.json. Si usas otro computador, adapta la ruta a su ubicacion.

3. PRIMER INICIO - EJECUTAR CADA COMANDO POR SEPARADO

Abre Terminal > New Terminal (Nueva terminal) en Visual Studio Code.
Copia solo los comandos, sin escribir PS ni los signos >>.
Presiona Enter despues de cada uno y espera a que termine.

PASO A: comprobar Node.js y npm:

node --version
npm.cmd --version

Ambos deben mostrar un numero de version. Si aparece "no se reconoce",
instala Node.js y vuelve a abrir Visual Studio Code. Si persiste,
reinicia Windows y comprueba nuevamente.

PASO B: entrar a la carpeta del proyecto:

cd "C:\Users\Vto\Desktop\fronend entrega 2\Proyecto FronEnd\nexus-ep2"

PASO C: confirmar que estas en el lugar correcto:

dir package.json

Debe aparecer package.json. Si no aparece, corrige la ruta antes de seguir.

PASO D: instalar pnpm (una vez por computador):

npm.cmd install --global pnpm@11.25.0

PASO E: instalar las dependencias del proyecto:

pnpm.cmd install --frozen-lockfile

Espera hasta que termine sin errores. Esto se hace al preparar una copia
nueva del proyecto o cuando cambian sus dependencias.

PASO F: iniciar la pagina:

pnpm.cmd dev

La terminal mostrara una direccion junto a Local, normalmente:

http://localhost:5173/

Manten Ctrl y haz clic en esa direccion, o copiala en tu navegador.
Usa el puerto que indique la terminal: puede cambiar si el 5173 esta ocupado.
Deja la terminal abierta mientras usas la pagina.

4. PARA INICIARLO LAS PROXIMAS VECES

Abre Visual Studio Code y una terminal. Ejecuta:

cd "C:\Users\Vto\Desktop\fronend entrega 2\Proyecto FronEnd\nexus-ep2"
pnpm.cmd dev

No necesitas reinstalar pnpm ni las dependencias cada vez.
Para detener el servidor, presiona Ctrl + C en esa terminal.

5. PRUEBAS Y VERSION PARA PUBLICAR

Desde la misma carpeta que contiene package.json:

pnpm.cmd test

Ejecuta las pruebas con Jasmine y Karma. Se requiere Edge o Chrome.
El informe de cobertura se genera en coverage/index.html.

pnpm.cmd build

Genera la version de produccion en dist. Ejecutalo despues de hacer cambios
si quieres actualizar la version compilada.

Para abrir esa version compilada con Node.js:

node scripts/serve.mjs

Luego abre http://127.0.0.1:8081/ y deja la terminal abierta.
Si el puerto esta ocupado, detiene el servidor anterior o ejecuta:

$env:PORT=8082
node scripts/serve.mjs

En ese caso abre http://127.0.0.1:8082/.
Para trabajar y ver los cambios mientras editas, usa pnpm.cmd dev.

6. ERRORES FRECUENTES

ERROR: ERR_PNPM_NO_IMPORTER_MANIFEST_FOUND o No package.json found
CAUSA: estas en la carpeta incorrecta.
SOLUCION: entra a la carpeta nexus-ep2 y comprueba con dir package.json.
Si ya estas en nexus-ep2, no vuelvas a ejecutar cd nexus-ep2.

ERROR: node o npm.cmd no se reconoce
SOLUCION: instala Node.js con Add to PATH y vuelve a abrir las terminales.

ERROR: pnpm.cmd no se reconoce
SOLUCION: ejecuta npm.cmd install --global pnpm@11.25.0.
Si sigue sin reconocerse, cierra y vuelve a abrir Visual Studio Code.

ERROR: no se puede acceder a localhost o conexion rechazada
SOLUCION: ejecuta pnpm.cmd dev y abre exactamente la direccion indicada.
La direccion funciona mientras el servidor esta encendido.

ERROR: se intenta abrir index.html con doble clic y no funciona
SOLUCION: inicia el proyecto con pnpm.cmd dev y abre la direccion Local.

7. IMPORTANTE PARA OTRO COMPUTADOR

Copia la carpeta completa que contiene package.json, src, public y el lock.
Instala Node.js y repite el primer inicio. No hace falta copiar node_modules;
se crea al instalar las dependencias. localhost siempre apunta al computador
donde se abre el navegador. El stock, carrito y sesion se guardan en el
navegador y no se comparten automaticamente entre computadores o puertos.

Si clonas el repositorio de GitHub, package.json esta directamente en la raiz
del repositorio clonado. Ejecuta los comandos desde esa carpeta.
